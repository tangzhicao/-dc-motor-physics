# 大学物理虚拟仿真课件 · 直流有刷电动机原理与微观机理
> 🚀 基于 Three.js + WebGL 的 3D 交互式大学物理仿真实验课件，8 幕递进式探索直流有刷电动机的核心工作原理、受力分析与多组电枢换向升级。

---

## ✨ 核心特性

- **8 幕启发式分步教学**：
  1. 纯磁场环境（匀强磁场分布）
  2. 通电矩形线框在磁场中受力（安培力、磁力矩与 J1202A 教学仿真电源）
  3. 直导线弯折演化为闭合矩形线圈
  4. 线圈无换向器阻尼平衡停转
  5. 引入半圆换向器与固定电刷（正面/侧面微观特写）
  6. 慢放与步进观察电流自动换向过程
  7. 完整直流有刷电动机持续高速运转
  8. 3D 零件爆炸图拆解自由探究
- **电枢线圈与换向片组数升级**：
  - **基础单组线圈**（1组环 · 2槽半圆片）：演示经典教学实验，转矩随 $|\cos\theta|$ 脉动 100%，垂直平衡面受力平衡停转。
  - **进阶双组正交线圈**（2组环 · 4槽换向器）：90° 垂直正交双线圈，配蓝色叠片硅钢转子铁芯，“轮流成为电磁铁”，转矩脉动率骤降至 29.3%，彻底消除死点。
  - **工业级多组密集电枢**（8组环 · 16槽换向器）：8 组径向对称线圈密集连续轮换，转矩波动率 $< 2\%$，实现工业级平滑恒定高速旋转。
- **左手定则与物理矢量可视化**：
  - 动态渲染磁场矢量 $\vec{B}$、导线电流矢量 $\vec{I}$、安培力矢量 $\vec{F} = I(\vec{L} \times \vec{B})$ 及电磁力矩 $\vec{M}$。
  - 电源断开时自动标识电流流动方向，便于根据左手定则先行推演。
- **高仿真 J1202A 学生电源**：
  - 具备 3D 可点击船型电源开关、电压粗调大旋钮、直流/交流双接线柱及真实柔性接线导线。

## 🛠️ 本地运行与开发

```bash
# 1. 克隆项目仓库
git clone <你的仓库地址>
cd <项目目录>

# 2. 安装项目依赖
npm install

# 3. 启动本地开发服务器
npm run dev

# 4. 构建生产包
npm run build
```

## 🌐 部署与上线 (GitHub Pages)

本项目已配置 GitHub Actions 自动构建与部署脚本 (`.github/workflows/deploy.yml`)：
1. 将代码推送至 GitHub 仓库的 `main` 分支；
2. 在 GitHub 仓库设置中开启 Pages：**Settings ➔ Pages ➔ Build and deployment ➔ Source 选择 "GitHub Actions"**；
3. GitHub 将自动完成打包与发布，生成可通过浏览器公开访问的课件网址：`https://<你的用户名>.github.io/<仓库名称>/`。
